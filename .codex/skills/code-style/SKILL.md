# 代码命名

从改动文件的编程语言和符号用途选择指南。本项目只涉及 Kotlin 与 Python。项目已有的公共 API、外部契约及明确生效的命名配置优先。

## 按语言阅读指南

| 语言 | 指南 |
|---|---|
| Kotlin | [属性、函数与常量](guides/kotlin.md) |
| Python | [模块、函数与非公开成员](guides/python.md) |

## 执行流程

1. 查看同一模块的同类符号和生效的命名配置。
2. 函数名表达动作或返回值，变量名表达所存内容。布尔值用能判断真假的词组，按语言习惯选择谓词。单位会影响使用时写进名称或使用带单位的类型。
3. 重命名时追踪实际引用。对外导出、序列化字段、反射、FFI 和命令行参数使用既有的外部拼写，内部标识符按需要独立命名。

## 按含义选词

| 要命名的内容 | 选词依据 | 示例 |
|---|---|---|
| 集合、数量、位置 | 集合用复数或集合名，数量、从零开始的索引和对外编号分别表达 | `entries`、`entryCount`、`entryIndex`、`pageNumber` |
| 状态、能力、历史结果 | 用一句可以回答“是 / 否”的话，分清当前是否打开、是否允许打开、是否已找到 | `isOpen`、`canOpen`、`found` |
| 读取、查找、解析 | 根据调用者获得的结果命名，优先复用库里对缺项、失败和转换已有的表达 | `readEntry`、`findEntry`、`parseHeader` |
| 时间、大小 | 类型已经表达单位就直接写含义，裸数值把单位写进名称 | 时长类型用 `timeout`，毫秒整数用 `timeoutMs`，字节数用 `sizeBytes` |
| 缩写 | 保留术语，按该语言组合大小写 | 同一 HTTP 客户端在 Kotlin 写 `HttpClient`，Python 类名写 `HTTPClient` |

表中拼写用于说明词义。真正写进代码时采用对应语言的形式。作用域越广，名字越要能单独理解。单词重复表达同一含义时，连同包名、类型名和调用处一起精简。

## 完成与维护

用项目现有的构建、类型检查或 lint 核对改动，检查调用方和外部契约。项目已形成且需长期沿用的命名例外记入对应语言指南，项目中的技能主源和镜像按现有入口同步。
