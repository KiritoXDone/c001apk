# 云端浏览历史

依据 2026-11-02 用户提供的手机 Reqable HAR 接入。抓包仅保存在仓库外，源码不包含 Cookie、token、真实浏览记录或设备标识。

- `GET https://api.coolapk.com/v6/user/hitHistoryList`，使用当前登录账号的既有鉴权链路。
- 首次加载和下拉刷新仅传 `page=1`，不携带旧游标。分页递增 `page`，原样传递首条 `firstItem` 与末条 `lastItem`；游标包含 `feed:`、`user:`、`product:` 等前缀，不能当作纯数字处理。
- `data` 是记录数组；字段为 `id`、`title`、`description`、`logo`、`url`、`historyType`、`typeName`、`dateline`。空数组表示没有更多内容，不能仅凭页长少于 20 判断结束。
- 列表按服务器顺序显示，按完整记录 ID 去重；记录使用服务器提供的 URL 跳转，因此支持动态、用户和数码页面。
- 浏览历史页右上角选单提供“本地”和“云端”切换，每次新进入默认本地；不使用顶部标签栏。本地显示清除按钮（空列表时禁用），云端隐藏清除按钮。账号或会话 revision 改变时清除云端状态并取消旧请求，失败保留当前账号已加载的列表并提供重试。
- 云端列表参考官方页面按“刚刚 / 今天早些时候 / 昨天或更早”分组：本应用将当天一小时内归为“刚刚”，其余按设备时区的自然日划分。头像统一圆角方形，时间与标题同行，摘要单行省略；分组内不另加箭头和分隔线。
- 本地历史及其清空操作保留；“记录本地浏览历史”开关只影响本机记录。

## 尚未确认的接口

此 HAR 没有独立的历史上传、删除或清空请求。抓包中的 `POST /v6/feed/detail` 也未在紧随其后的历史响应中体现新增记录，因此不能据此认定它会同步历史。

本次只接入云端读取，不上传本机旧历史，不改动动态详情请求，不提供云端删除或清空，也不承诺本应用新浏览的记录会写入云端。后续需补充明确的写入协议证据后再接入。
